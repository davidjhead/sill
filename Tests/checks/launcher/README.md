# `launcher`

**Checks:** the Mac client's launcher model (`LauncherModel`): one Desktop per display of a host that lists its `displays` (each its tagged Desktop window, the main one said, the open one marked), else the one Desktop named after the stop it shows (#91) with a blank name as its number and a stop out of range unnamed; windows in the bar's order, an untitled one by its app's name, the ones open here marked; every app A to Z (case ignored), a twice-listed app once, a windowed app that is not installed added, the running ones marked; the favourites in the order added (only apps the other Mac lists, each once, marked in All Apps too) and a right-click's toggle (added last, removed in place); Recent (only the apps used and the Desktops opened from here, each Desktop by a key of its own, latest first, a tie A to Z, empty until something is, none of it in the A to Z order, a search still through every app and through Recent's list); and the search: trimmed, case and accents ignored, favourites searched too, windows found by their app and the Desktop by its display's name, a name or a word in it starting with the query before names that only contain it, each in its section's order, and Return's first choice (an app, else a window, else a Desktop; none when nothing matches)

**Compiles:** `Sources/MacClient/LauncherModel.swift` with StreamProtocol's sources as one module (`swiftc`)
